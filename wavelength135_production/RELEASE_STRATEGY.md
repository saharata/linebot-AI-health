# 📅 Release Strategy — Trilogy "สายโลก"

> Hybrid release plan: front-loaded launches + Shorts engine
> Total: 15 long-form EPs + 45 Shorts ใน 10 สัปดาห์
> Channel: เหวินลี่เล่า (YouTube + TikTok + IG Reels)

---

## หลักการ

1. **Long-form** = retention engine (ad revenue, depth)
2. **Shorts** = discovery engine (algorithm push, ฟรี traffic)
3. **Binge drop** ต้นซีซั่น = ให้ algorithm จับว่าช่องมี momentum
4. **Weekly cadence** กลางๆ ซีซั่น = sustainable
5. **Break ระหว่างเล่ม** = ให้ audience ย่อย + พัก production

## 🎬 Shorts Templates (60 วินาที each)

### Format มาตรฐานทุก Short

```
0–3s   HOOK — คำถาม/ภาพสะดุด/ตัวเลข
3–8s   SET UP — ใครคืออะไร อยู่ที่ไหน
8–50s  BUILDUP — เล่า มี text overlay ทุกประโยค
50–55s PAYOFF — เปิด emotion / pivot
55–60s CTA — "เรื่องเต็มใน YouTube"
```

**Visual rule**: เปลี่ยน shot ทุก 2–3 วินาที, ใช้ on-screen text 100% (คน scroll เงียบ)
**Audio rule**: ใช้ narration เดิมจาก EP + ดนตรี free ใต้

## 📊 KPIs ที่ต้อง track

### สัปดาห์ที่ 1 (W0)
- Subscribers ใหม่: เป้า 200-500
- Long-form views EP1: เป้า 500-2K
- Shorts views/อัน: เป้า 2K-10K
- Watch time avg: เป้า 7+ นาที (EP 20 นาที = 35%+ retention)
- Comments มี emoji ❤️ 🎬 = audience hooked

### สัปดาห์ที่ 4 (เริ่มเล่ม 2)
- Subscribers สะสม: เป้า 1K-5K
- Long-form views/EP: เป้า 1K-5K
- Shorts viral 1 อัน (>50K) = ช่องเริ่ม work

### สัปดาห์ที่ 10 (finale)
- Subscribers: เป้า 3K-20K (ขึ้นกับ viral)
- Ad revenue เริ่มเข้า (1K+ watch hours)
- Sponsor inbound? (ที่ 5K+ subscribers)

### หากไม่เป็นไปตามเป้า — ปรับ:
- Shorts views ต่ำ → เปลี่ยน hook 3 วินาทีแรก
- Long-form watch time ต่ำ → ตัด intro ให้สั้นลง
- Subs ไม่ขึ้น → end screen ที่ pin CTA แรงกว่า

## 🎯 Decision points สำหรับ user

หลัง W0 launch:
1. **ถ้า viral** (>50K Shorts views) → push EP4 เร็วขึ้น
2. **ถ้า flat** (<5K Shorts views) → พัก, ปรับ hook, รอ Shorts ฮิตก่อนปล่อย EP4
3. **ถ้า binge หมด** (EP1-3 watch >70%) → audience hungry, ปล่อย EP4 ในวันเสาร์แทนจันทร์
