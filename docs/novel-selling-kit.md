> เครื่องมือพร้อมใช้สำหรับวางขาย ebook / print on demand

---

## 1. ปกหลัง (Back Cover Blurb) — ใช้บนหน้าขาย

### เวอร์ชันยาว (หลังปก/หน้า product)

> **เมื่อโลกถูกแบ่งด้วยกำแพงที่เราไม่ได้สร้าง คนตัวเล็กๆ จะยังเป็นมนุษย์ต่อกันได้อย่างไร**
>
> ปี 2026 เฉินเหวินลี่ วิศวกรหญิงวัยยี่สิบเก้า ก้าวเข้าสู่โรงงานผลิตชิปในเมืองเล็กของจีน พร้อมเครื่องจักรเก่าเครื่องหนึ่งที่ทุกคนเรียกว่า "ลุง" และความฝันที่เกือบเป็นไปไม่ได้ — สร้างสิ่งที่ทั้งโลกบอกว่าประเทศของเธอทำเองไม่ได้
>
> สิบห้าปีข้างหน้า เธอจะได้พบกับเอวา วิศวกรอีกฝั่งกำแพงที่เธอไม่มีวันได้เป็นเพื่อนด้วยอย่างเต็มใจ ได้เห็นครูของเธอวางอิฐก้อนแรกแล้วจากไปก่อนเห็นปลายทาง และได้ค้นพบว่าชัยชนะที่แท้จริง อาจไม่ใช่การเป็นที่หนึ่ง
>
> เรื่องราวของแสงความยาวคลื่นหนึ่ง ที่ไม่เคยรู้จักพรมแดน — และคนที่ใช้ทั้งชีวิตไล่ตามมัน
>
> *"ฟิสิกส์ไม่มีสัญชาติ มีแต่เราที่สร้างกำแพง และมีแต่เราที่รื้อมันลงได้"*

### เวอร์ชันสั้น (สำหรับ thumbnail / โซเชียล)

> สิบห้าปี หนึ่งวิศวกรหญิง และสงครามที่ทำด้วยแสง
> เรื่องของคนสองฝั่งกำแพง ที่ยังพยายามเป็นมนุษย์ต่อกัน

### เวอร์ชันหนึ่งบรรทัด (logline)

> วิศวกรหญิงใช้เวลาสิบห้าปีไล่ตามแสงที่ไม่มีใครเชื่อว่าประเทศเธอจะสร้างได้ — และค้นพบว่าการไม่เป็นที่หนึ่ง ไม่ได้แปลว่าแพ้

## 7. ปก — Concept สำหรับออกแบบ

### Visual direction
- **พื้นหลังดำ/น้ำเงินเข้ม** — โทน clean room
- **จุดเด่น**: ลำแสงสีฟ้าอมขาว (แทน EUV 13.5nm) ตัดผ่านความมืด
- **เงา**: silhouette ผู้หญิงในชุด clean room ยืนเล็กๆ หน้าเครื่องจักรใหญ่
- **ฟอนต์ชื่อเรื่อง**: minimal, ทันสมัย, สีขาว
- **อารมณ์**: เหงา ยิ่งใหญ่ มีความหวัง (แบบโปสเตอร์หนัง Denis Villeneuve)

### Prompt สำหรับ gen ปก (Midjourney/Seedance image)
```
Book cover, minimalist cinematic. A lone female figure in a yellow
clean-room suit stands small before a massive glowing machine in a
dark semiconductor facility. A single beam of pale blue-white light
(13.5nm EUV) cuts through the darkness. Deep navy-black background,
volumetric light, sense of solitude and grandeur. Space at top for
title text. Photorealistic, film poster aesthetic. Vertical 2:3.
```

## 10. แปลงไฟล์เป็น EPUB (ฟรี)

ไฟล์ `MANUSCRIPT-full-novel.md` เป็น Markdown มี `\newpage` คั่นหน้าแล้ว

**วิธีแปลง:**
1. **Pandoc** (ฟรี, command line):
   ```
   pandoc MANUSCRIPT-full-novel.md -o novel.epub --metadata title="แสงที่ความยาวคลื่นสิบสามจุดห้า"
   ```
2. **Reedsy Book Editor** (ฟรี, เว็บ): paste เนื้อหา → export EPUB + PDF สวยงาม
3. **Calibre** (ฟรี): import markdown → convert to EPUB/MOBI

แนะนำ **Reedsy** — ฟรี จัดหน้าสวย มี template มืออาชีพ export ได้ทั้ง EPUB และ print-ready PDF
