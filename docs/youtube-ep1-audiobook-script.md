## โน้ตสำหรับผู้บรรยาย

**สัญลักษณ์ที่ใช้:**
- `[…]` = คำสั่งทิศทาง (pace / silence / emphasis) — ไม่อ่านออกเสียง
- `«…»` = บทพูดของตัวละคร — เปลี่ยนน้ำเสียงเล็กน้อย
- `***` = หยุดยาว 2 วินาที (สำหรับขึ้นบทใหม่)

**ดนตรีพื้นหลัง:**
- เบส: piano ambient + drone synth, BPM 55–65
- ลด ducking -10 dB ตอนผู้บรรยายพูด
- ค่อยๆ ดังขึ้นในจังหวะหยุดดราม่า

**SFX (เบามาก ใส่เพื่ออารมณ์):**
- เสียงเครื่องจักรครางต่ำ (Hum) — ตอนเล่าฉาก clean room
- เสียงพิมพ์ข้อความ (LINE notification) — ตอนข้อความแม่
- เสียงไวน์ในแก้ว / ภัตตาคารเงียบๆ — ตอนฉากสิงคโปร์

- บทที่ ๑: ~6 นาที (~700 คำไทยที่อ่าน ~120 wpm + pause ดราม่า)

### Workflow แนะนำ
1. **อัด narration ทั้งตอน** ผ่าน ElevenLabs (Liam) — รันใน script เดียวกับที่ผมทำไว้
2. **Export เป็น 3 ไฟล์** (บท ๑ / ๒ / ๓) เพื่อใส่ดนตรีเปลี่ยนช่วงง่าย
3. **CapCut**:
   - Track 1: video (opener "ลุง" + static cover image + occasional B-roll)
   - Track 2: narration audio
   - Track 3: ambient music (Pixabay cinematic ambient)
   - Track 4: SFX (machine hum, LINE notif, wine glass)
4. **Visual ระหว่าง narration** — แค่ใช้:
   - Cover art static (อยู่กลางจอ)
   - หรือ slow Ken Burns zoom บนภาพ Seedance ที่มี
   - ON-SCREEN TEXT บรรทัดเดียวตอน "เราไม่ต้องเป็นที่หนึ่ง..." (1 ครั้ง)
   - ไม่ต้องตัดบ่อย — ปล่อยให้เสียงเล่าเรื่อง
