# In-Clinic Marketing Plan — Solo Weight Loss Specialist

> Context: In-clinic only (no remote ads), solo doctor, weight loss specialist, existing clinic + LINE CRM, budget ฿0–500/month

---

## Executive Summary

โฟกัสที่ **5 ช่องทาง organic + free** เพราะไม่ต้องผ่าน อย./สสจ. และไม่ต้องลงทุน ad

| Channel | งบ/เดือน | บทบาท | ROI |
|---|---|---|---|
| 1. Google Business Profile | ฿0 | Walk-in discovery | สูงสุด |
| 2. Existing patient base (LINE CRM) | ฿0 | Retention + referral | สูง |
| 3. Educational organic content | ฿0–500 | Authority + ค้นเจอ | กลาง-สูง |
| 4. Local partnership | ฿0 | Cross-referral | สูง |
| 5. Referral program | ฿500–1,000/refer | Word-of-mouth engine | สูง |

**เป้า 6 เดือน**: 30–60 active patients, MRR ฿250K–700K
**เป้า 12 เดือน**: 100–200 active patients, MRR ฿800K–2M

## Channel 1: Google Business Profile (ทำก่อนเลย)

### ทำไมสำคัญที่สุด
- 80%+ ของคนหาคลินิกใหม่ search Google Maps ก่อน
- ฟรี 100%
- ไม่ต้องขอ อย./สสจ. อนุมัติ
- รีวิว 4.5+ ดาว 50+ รีวิว = walk-in traffic ตลอดเวลา

### Setup Checklist
- [ ] สร้าง/claim Google Business Profile
- [ ] ใส่รูปคลินิก 10+ รูป (หน้าร้าน, ภายใน, ห้องตรวจ, ตัวคุณ)
- [ ] เวลาเปิด-ปิดถูกต้อง
- [ ] เบอร์โทร + LINE OA link
- [ ] Description: "คลินิกเวชกรรม ดูแลโดยแพทย์เฉพาะทาง..." (ไม่ใส่ชื่อยา)
- [ ] Service list: "ปรึกษาน้ำหนัก", "ตรวจสุขภาพเบื้องต้น", "ติดตามผล online"
- [ ] Post update สัปดาห์ละ 1 ครั้ง (ฟีเจอร์เหมือน FB post)

### Review Strategy
- หลัง visit ทุกครั้ง → ส่ง LINE message ขอรีวิว Google
- Template: "ขอบคุณที่ไว้ใจให้ดูแลค่ะ ถ้าสะดวกฝากรีวิวให้คลินิกที่ [link] ด้วยนะคะ"
- เป้า: 5 รีวิว/สัปดาห์ ใน 3 เดือนแรก → 60 รีวิว
- ตอบทุกรีวิว (positive + negative) ภายใน 24 ชม.

### Local SEO
- Keywords ที่ต้อง rank: "คลินิกลดน้ำหนัก [เขต]", "หมอเฉพาะทางลดน้ำหนัก [เขต]", "ปรึกษาน้ำหนัก [เขต]"
- ห้ามใส่: ชื่อยา, "รักษาเบาหวาน", ตัวเลขรับประกัน

## Channel 2: Existing Patient Base (Goldmine)

### หลักการ
คนไข้เดิม 1 คน = LTV สูงกว่า new acquisition 5–10 เท่า + refer เพื่อนได้ ~3 คน/ปี

### LINE OA Strategy (ใช้ codebase ที่มี)

**Rich Menu (เมนูถาวร)**:
- ปรึกษาออนไลน์ (เฉพาะคนไข้เดิม follow-up)
- นัดมาคลินิก
- ดู package / membership
- ข้อมูลสุขภาพของฉัน (AI dashboard)
- FAQ

**Broadcast Calendar (1–2 ครั้ง/เดือน)**:
- Educational: "5 ข้อสังเกตเวลาน้ำหนักไม่ลด"
- Service reminder: "ใครยังไม่เช็คเลือด 3 เดือนแล้ว ทักมาได้นะคะ"
- VIP offer: "Member ได้ส่วนลด lab 20% เดือนนี้"
- Birthday wish + voucher
- **ห้าม**: โฆษณายา, ก่อน-หลัง

**Auto-message Sequence (new friend)**:
- Day 0: Welcome + แนะนำคลินิก + LIFF assessment
- Day 1: ส่ง educational content 1 ชิ้น
- Day 3: ถามว่ามีคำถามอะไรไหม
- Day 7: เชิญนัดปรึกษา

### Membership Program (in-clinic)
| Tier | ราคา | สิทธิ์ |
|---|---|---|
| Basic | ฿2,990/3 เดือน | 3 visit + AI dashboard + LINE support |
| Standard | ฿9,990/6 เดือน | 6 visit + 1 lab + priority booking |
| Premium | ฿19,990/12 เดือน | 12 visit + 2 lab + 1:1 LINE + birthday voucher |

**Key**: เก็บเงินก้อน = lock retention + cash flow ดี

## Channel 3: Educational Organic Content

### หลักการ
**Educational ≠ Advertising** — ไม่ต้องขออนุญาต ตราบใดที่:
- ไม่ระบุชื่อยา
- ไม่ระบุว่าคลินิกขายยานี้
- ไม่มี CTA แบบ hard sell
- เป็นข้อมูลทั่วไปเรื่องสุขภาพ

### Platform & Cadence

| Platform | ความถี่ | format |
|---|---|---|
| TikTok | 5–7/สัปดาห์ | 15–30 วินาที, subtitle ไทย |
| IG Reels | 5–7/สัปดาห์ | Cross-post จาก TikTok |
| YouTube Shorts | 5–7/สัปดาห์ | Cross-post จาก TikTok |
| YouTube long-form | 1/สัปดาห์ | 8–15 นาที, SEO ยาว |
| Threads | 3–5/สัปดาห์ | Text Q&A, แชร์ความคิด |
| Facebook | 3/สัปดาห์ | สำหรับกลุ่มอายุ 40+ |

### Content Pillars
| Pillar | % | ตัวอย่าง |
|---|---|---|
| Educational | 40% | "ฮอร์โมนกับน้ำหนัก", "ทำไม IF ไม่ work กับบางคน" |
| Myth-busting | 25% | "5 ความเชื่อผิดเรื่องลดน้ำหนัก" |
| Behind-the-scene | 20% | day in clinic, Q&A |
| Social proof | 15% | mindset stories (ไม่ใช่ before/after) |

### Workflow 1 ชม. = content 1 สัปดาห์
1. AI gen 50 หัวข้อ (5 นาที)
2. AI ร่าง 7 scripts (10 นาที)
3. คุณแก้ภาษา (15 นาที)
4. ถ่าย 7 clips ในคลินิก (20 นาที)
5. CapCut auto-subtitle + cut (10 นาที)
6. Review compliance + lock (5 นาที)

### Tools (ฟรีทั้งหมด)
- ChatGPT free / Claude free — script
- CapCut free — edit + subtitle
- Canva free — thumbnail
- มือถือคุณ — กล้อง
- Ring light: ฿500 (one-time)

## Channel 4: Local Partnership

### Target Partners (ในรัศมี 5 กม. จากคลินิก)

| Partner | Cross-referral logic |
|---|---|
| ฟิตเนส / โยคะ studio | คนออกกำลังกายแต่น้ำหนักไม่ลด = lead เรา |
| คลินิกผิวหนัง / ความงาม | คนไข้ลดน้ำหนักก่อนทำผิว |
| คลินิกสูตินรี | PCOS, post-partum |
| Pharmacy ใหญ่ในย่าน | refer คนที่ถามเรื่อง weight |
| ร้านอาหาร healthy | flyer แลกกัน |
| โรงเรียน/บริษัทใกล้คลินิก | lunch-and-learn HR talk |

### Tactics
- **Lunch-and-learn** ที่บริษัท HR — talk 30 นาทีเรื่องสุขภาพพนักงาน → lead จาก HR
- **MOU referral**: 10% discount ทั้งสองฝ่าย (legal — ไม่ใช่ค่าคอมยา)
- **Joint Facebook Live**: คุยกับ trainer/PT เรื่อง weight management

### Cost
- ส่วนใหญ่ ฿0
- Lunch-and-learn: อาจซื้อ snack ให้ผู้ฟัง ฿500–1,000/ครั้ง

## Channel 5: Referral Program

### Structure
- คนไข้เดิม refer เพื่อนใหม่ → ทั้งคู่ได้ ฿500–1,000 credit
- Credit ใช้กับ consult / lab / membership ได้
- Track ผ่าน LINE OA referral code

### Math
- คนไข้ดี 1 คน × refer 3 คน/ปี × conversion 30% = ลูกค้าใหม่ 1 คน/ปี/คนไข้
- 50 คนไข้เดิม → 50 ลูกค้าใหม่/ปี free
- CAC = ฿500–1,000 (จ่ายต่อเมื่อ refer สำเร็จ)

### Activation
- หลัง visit ครั้งที่ 2 (เห็นผล) → ส่ง LINE แจ้ง program
- Personalize: "คุณ A เห็นผลใน 6 สัปดาห์แล้ว ถ้ามีเพื่อนสนใจแชร์ code นี้ได้นะคะ"
