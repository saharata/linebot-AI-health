# เล่ม 2 — หนังสือ FND / PPPD (Concept + โครงเล่ม + แผนขาย)

> หนังสือสุขภาพสำหรับคนทั่วไป เขียนโดยแพทย์เฉพาะทางระบบประสาท
> กลุ่มเป้าหมาย: คนที่เวียนหัว เดินเซ ปวดหัว มานานหลายปี ตรวจไม่เจอ ยังไม่หาย
> Dual purpose: ขายเป็นหนังสือ + สร้าง authority + lead magnet เข้าคลินิก

---

## ชื่อหนังสือ — ตัวเลือก

### ⭐ ชื่อหลักที่แนะนำ

> # "ไม่เป็นไร... แต่ไม่หาย"
> ### เมื่อทุกผลตรวจปกติ แต่คุณยังทรมาน

**ทำไมชื่อนี้ทรงพลังที่สุด:**
- จับ "ความเจ็บปวดที่ไม่มีใครเชื่อ" ได้ทันที — คนกลุ่มนี้ถูกบอกว่า "ไม่เป็นไร" มาเป็นปีๆ
- ขัดแย้งในตัว (paradox) → สะดุดตา จำง่าย
- คนที่เป็น PPPD/FND อ่านปุ๊บรู้เลยว่า "นี่พูดถึงฉัน"
- ใช้เป็น hashtag ได้: #ไม่เป็นไรแต่ไม่หาย

### ตัวเลือกสำรอง

| ชื่อ | จุดเด่น | โทน |
|---|---|---|
| **"โลกที่ไม่หยุดโคลง"** | poetic, ภาพ PPPD ชัด (โคลงเรือ) | วรรณกรรม |
| **"สมองที่กลัวการล้ม"** | อธิบาย mechanism PPPD ตรงๆ | วิทยาศาสตร์ |
| **"งง"** | สั้น = brand, ตรงคำที่คนค้น | minimal/ทันสมัย |
| **"เวียนหัวที่ไม่มีในผลแล็บ"** | เจาะ pain point ตรง | ตรงไปตรงมา |
| **"หัวที่ไม่เคยนิ่ง"** | กว้าง ครอบทั้งปวดหัว+เวียนหัว | กลางๆ |
| **"ป่วยจริง ตรวจไม่เจอ"** | ตรง FND core | direct |

### ชื่อรอง (subtitle) ที่จับคู่ได้
- "คู่มือเข้าใจ PPPD, FND และไมเกรนเวียนหัว สำหรับคนที่หาคำตอบมานาน"
- "เรื่องของอาการที่หมอทั่วไปไม่ค่อยรู้จัก — และทางออกที่มีจริง"

---

## Positioning — ทำไมหนังสือเล่มนี้ขายได้

### ช่องว่างในตลาด
- หนังสือ PPPD/FND ภาษาไทย: **แทบไม่มีเลย**
- คนค้น "เวียนหัวเรื้อรัง" "เดินเซ" "งงๆ ตลอดเวลา" ใน Google — เจอแต่ข้อมูลกระจัดกระจาย
- คนกลุ่มนี้ทุกข์มา 3-10 ปี, เปลี่ยนหมอหลายคน, พร้อมจ่ายเพื่อ "คนที่เข้าใจ"

### Unique angle
หนังสือสุขภาพทั่วไป = "วิธีดูแลตัวเอง" (generic)
เล่มนี้ = **"คุณไม่ได้บ้า และคุณไม่ได้แกล้ง — นี่คือสิ่งที่เกิดขึ้นในสมองคุณจริงๆ"**

→ มันคือ **หนังสือที่ให้ความเข้าใจ ไม่ใช่แค่ความรู้** — emotional hook แข็งกว่าหนังสือ how-to ทั่วไป

### ผู้เขียน = แพทย์เฉพาะทางจริง
- ไม่ใช่ influencer, ไม่ใช่ ghostwriter
- เคสจริง (anonymized), ภาษาที่หมอใช้คุยกับคนไข้
- ความน่าเชื่อถือสูงสุด

## โครงเล่ม (Table of Contents)

### ภาค 1 — "คุณไม่ได้บ้า" (Validation)
*เป้าหมาย: ให้คนอ่านรู้สึกว่ามีคนเข้าใจ ภายใน 10 หน้าแรก*

- บทที่ 1: จดหมายถึงคนที่หาคำตอบมานาน
- บทที่ 2: "ผลตรวจปกติ" ไม่ได้แปลว่า "ไม่มีอะไร"
- บทที่ 3: เรื่องของคุณ A — เวียนหัว 7 ปี เจอหมอ 12 คน (เคส anonymized)
- บทที่ 4: ทำไมการแพทย์ถึงมองข้ามโรคแบบนี้

### ภาค 2 — "เกิดอะไรขึ้นในสมองคุณ" (Understanding)
*เป้าหมาย: อธิบายวิทยาศาสตร์แบบเข้าใจง่าย ให้ความหวังว่ามันมีคำอธิบาย*

- บทที่ 5: PPPD — เมื่อสมองกลัวการล้มเกินไป
- บทที่ 6: Vestibular migraine — เมื่อไมเกรนมาพร้อมเวียนหัว
- บทที่ 7: FND — โรคที่ระบบทำงานผิด ทั้งที่อวัยวะปกติ
- บทที่ 8: ทำไมความเครียดทำให้แย่ลง (และไม่ได้แปลว่าเป็นโรคจิต)
- บทที่ 9: สมอง ตา หูชั้นใน และการทรงตัว — ทีมที่ทะเลาะกัน

### ภาค 3 — "ทางออกมีจริง" (Hope + Action)
*เป้าหมาย: ให้เครื่องมือ + ความหวังที่อิงหลักฐาน*

- บทที่ 10: ข่าวดี — 80% ของ PPPD ดีขึ้นถ้ารักษาถูก
- บทที่ 11: Vestibular rehabilitation — ฝึกสมองให้เลิกกลัว
- บทที่ 12: ยา — อะไร work อะไรไม่ work (อธิบายหลักการ ไม่ระบุยี่ห้อ)
- บทที่ 13: ปรับชีวิตประจำวัน — แสง จอ การนอน คาเฟอีน
- บทที่ 14: เมื่อไหร่ควรหาหมอ และหาหมอแบบไหน

### ภาค 4 — "เดินต่อ" (Living with it)
- บทที่ 15: วันที่ดีและวันที่แย่ — การอยู่กับอาการเรื้อรัง
- บทที่ 16: คุยกับครอบครัวยังไงให้เขาเข้าใจ
- บทที่ 17: จดหมายปิดท้าย — คุณไม่ได้เดินคนเดียว

### ภาคผนวก
- แบบประเมินอาการตัวเอง (เชื่อมกับ AI symptom checker ของคลินิก)
- Headache & dizziness diary template
- คำถามที่ควรถามหมอ
- แหล่งข้อมูลเพิ่มเติม

## เล่มนี้กับคลินิกเชื่อมกันยังไง (Funnel)

```
หนังสือ "ไม่เป็นไร...แต่ไม่หาย"
   = authority + emotional connection
        ↓
ภาคผนวก: แบบประเมิน → QR code → AI symptom checker
        ↓
คลินิก งง-งง เดินเซ ปวดหัว ไมเกรน
   = ปรึกษา 5 นาที → รักษา
```

- หนังสือ = lead magnet ที่ **คนจ่ายเงินซื้อ** (ไม่ใช่แจกฟรี → คนเห็นค่า)
- ทุกเล่มมี QR code ท้ายเล่ม → LINE OA + symptom checker
- คนอ่านจบ = warm lead ที่เชื่อใจคุณแล้ว → conversion สูง

## แผนการขาย (Monetization)

### ช่องทาง
| ช่องทาง | ราคา | margin |
|---|---|---|
| **Ebook (PDF/EPUB)** ขายเองผ่าน LINE/เว็บ | ฿199-299 | ~95% |
| **Print on demand** (Amazon KDP / นายอินทร์ / Fictionlog) | ฿350-450 | ~30-40% |
| **เล่มจริงในคลินิก** | ฿390 | ~60% |
| **Audiobook** (อ่านเอง หรือ AI TTS) | ฿249 | ~90% |
| **แจกฟรีบทแรก** (PDF) | ฿0 | lead gen |

### กลยุทธ์ราคา
- **บทที่ 1-3 แจกฟรี** เป็น PDF → ดึงเข้า LINE OA
- เล่มเต็ม ขาย ebook ฿249
- Bundle: หนังสือ + ปรึกษา 5 นาที = ฿590 (anchor)

### Launch plan
1. **เขียนเสร็จ** → จัดรูปเล่ม ebook
2. **บทแรกฟรี** → ลง Threads/FB/คลินิก LINE OA
3. **Pre-order** ผ่าน LINE → ส่วนลด early bird
4. **เปิดตัว** พร้อม content series (TikTok อธิบาย PPPD ตามบทในหนังสือ)
5. **Print on demand** เมื่อ ebook พิสูจน์ demand แล้ว

### ตัวเลขประมาณการ (conservative)
- ขาย ebook 100 เล่ม/เดือน × ฿249 = ฿24,900/เดือน
- + lead เข้าคลินิก 10-20 คน/เดือน (ที่ LTV สูงกว่ามาก)
- → หนังสืออาจไม่ใช่รายได้หลัก แต่เป็น **เครื่องดึงคนไข้ที่ทรงพลังที่สุด**

## ความเสี่ยง / ข้อควรระวัง

| เรื่อง | วิธีจัดการ |
|---|---|
| ห้ามให้คำวินิจฉัยในหนังสือ | ใช้ภาษา "อาจเข้าข่าย" + disclaimer ทุกบท |
| ห้ามโฆษณายา (พ.ร.บ.ยา) | อธิบายหลักการยา ไม่ระบุชื่อการค้า |
| ความคาดหวังเกินจริง | ย้ำว่า "ดีขึ้น" ไม่ใช่ "หายขาด 100%" |
| ขายตรงเกินไป | หนังสือต้องให้คุณค่าจริง คลินิกเป็น option ไม่ใช่ sales pitch |
| ลิขสิทธิ์เนื้อหาการแพทย์ | เขียนใหม่ด้วยภาษาตัวเอง อ้างอิง source ท้ายเล่ม |

## ทำไมเล่มนี้ "เจ๋ง" กว่าหนังสือสุขภาพทั่วไป

1. **Niche ที่ไม่มีคู่แข่งภาษาไทย** — first mover
2. **Emotional hook แข็ง** — "คุณไม่ได้บ้า" โดนใจคนทุกข์
3. **ผู้เขียนคือหมอจริง** — authority สูงสุด
4. **เชื่อมธุรกิจ** — ขายหนังสือ + ดึงคนไข้ พร้อมกัน
5. **Scalable** — ebook margin 95%, ขายได้ตลอด 24 ชม.
6. **Series potential** — เล่ม 3: ไมเกรน, เล่ม 4: นอนไม่หลับ ฯลฯ
